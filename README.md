# Project Name
- Waste Wise Project 
- **WasteWise** is an interactive educational solution that raises awareness among children and young people about the importance of waste sorting and recycling through a fun and     intelligent learning experience implemented in schools and universities. Its mission is to transform the simple act of throwing away waste into an engaging learning moment, guiding younger generations toward sustainable and eco-responsible behaviors.
